#### 2.1.5残差检验

![](./image/residual.png)

模型的结构（趋势、周期性）拟合得尚可，残差已经没有了自相关，但是异方差性（厚尾）和严重的初始异常值是当前模型最大的问题。

#### 残差时序图

- 数据中存在极其强烈的异常值（Outlier）或结构性突变，导致模型在该时期产生了极大的预测误差

#### 残差分布图

- 显示残差分布呈现尖峰厚尾形态；
- 残差不服从正态分布，模型基于正态分布的假设（如预测区间、显著性检验）将不再准确。

#### QQ图

- 图中点在中部大致沿直线分布，但在两端（尤其是尾部）明显偏离直线，左尾下偏、右尾上偏，进一步证实了厚尾特征。
- 这再次确认残差非正态，但Q-Q图对尾部偏差更敏感，有助于判断极端值风险。

#### 残差自相关

- 残差中没有显著的自相关性（即残差是“白噪声”）。模型已经成功提取了时间序列中的线性依赖关系，没有遗漏周期或趋势信息

#### 2.1.6 标准化残差

数据存在条件异方差效应，引入GARCH模型

![](./image/residual_normal.png)

- 参数显著性：ω、β₁、ν 的 p 值都小于 0.05，估计显著。

- 波动持续性：α + β = 0.3016742 + 0.5959155 = 0.89759，小于 1，满足平稳性条件，表明波动冲击以较慢速度衰减。

- 自由度 ν = 4.18，明显小于正态分布（ν→∞），说明残差尾部较厚，采用 t 分布是合理的。

#### 2.1.7波动率预测

覆盖率仅为 38%，远低于 95% 的理论值，模型对预测区间严重低估
